# i18n/ — multilinguismo (SPEC §7)

- `locales.toml` — cadeias de fallback, variantes regionais
- `glossary/` — terminologia por locale, revista à mão (`pt-PT.csv`, `pt-BR.csv`, `en.csv`, …)
- `labels/` — rótulos por conceito e locale, com estatuto
- `divergences.csv` — pt-PT vs pt-BR, en-GB vs en-US (só na F4)
- `untranslatable.csv` — conceitos sem equivalente + glosa
- `review_queue/` — fila de revisão humana
